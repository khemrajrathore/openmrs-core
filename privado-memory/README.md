# ROPA — Record of Processing Activities

Generated from OpenMRS Core source code analysis.

## Processing Activities

- [PA-001: Patient Registration & Demographic Management](ropa/PA-001_patient_registration.md) — Manages patient demographic information (creation, update, retrieval, voiding).
- [PA-002: Clinical Data Collection](ropa/PA-002_clinical_data_collection.md) — Collects clinical data during patient encounters, including observations and linked orders.
- [PA-003: Order Management](ropa/PA-003_order_management.md) — Creates, updates, voids and retrieves clinical orders (prescriptions, lab tests, referrals).
- [PA-004: Diagnosis & Condition Recording](ropa/PA-004_diagnosis_condition_recording.md) — Records patient diagnoses and chronic conditions.
- [PA-005: Allergy Management](ropa/PA-005_allergy_management.md) — Maintains patient allergy information for safety alerts.
- [PA-006: User/Staff Account Management](ropa/PA-006_user_account_management.md) — Creates, updates and deletes user accounts, roles and privileges that control system access.
- [PA-007: Visit Tracking](ropa/PA-007_visit_tracking.md) — Tracks when and where a patient receives care (visit start/end, location).
- [PA-008: Program Enrollment](ropa/PA-008_program_enrollment.md) — Enrolls patients into health programs and manages program workflows.
- [PA-009: HL7 Data Exchange](ropa/PA-009_hl7_data_exchange.md) — Imports patient/encounter data from external systems via HL7 and exports HL7 messages outward.
- [PA-010: System Notifications](ropa/PA-010_system_notifications.md) — Sends email or in‑system notifications that may contain patient‑related information.
